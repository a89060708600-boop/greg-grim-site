# Грег Грим — сайт писателя

Основной адрес: https://greggrim.ru/.
Проект Vercel: `bird11/greg-grim-site`, репозиторий `greg-grim-site`.
Пуш в `main` автоматически публикуется на Vercel.

## Устройство

Статический сайт без сборки и библиотек: `index.html`, `assets/css/site.css`,
`assets/js/site.js`. Шрифты Oswald, Alegreya и IBM Plex Mono хранятся в
`assets/fonts` вместе с OFL-лицензиями; запросов к Google Fonts нет.

Канонический адрес страницы — `greggrim.ru`. Ресурсы страницы загружаются с
`https://greg-grim-site.vercel.app/assets/` — адреса того же проекта Vercel.
Относительные URL внутри `fonts.css` разрешаются относительно этого адреса.
При смене проекта нужно обновить адрес ресурсов в `index.html`.
Для CSS и JS используется параметр версии; меняйте его при следующем выпуске.

- `/books/strashnye-skazki/`: новая редакция, 818 слов из начала главы
  «Крыльцо», бесплатное чтение на АТ/Литнете и пояснение о прежнем названии

  настоящие фрагменты по 532 / 477 слов из проектных вычитанных рукописей.

- Главная ведёт к фрагментам и площадкам; в «Закулисье» одна датированная

  отчёты хранятся в проекте BookCraft вне репозитория сайта.

## Полный рассказ «Чёрная рука»

`/stories/chyornaya-ruka/` — самостоятельная история целиком: 176 абзацев,
2847 слов, без изменения авторского текста из резервной сборки от 22.10.2026.
Чтение открыто сразу, без JavaScript и скрывающих текст элементов. Есть
переходы к книге, другим книгам и авторскому Telegram, а также стиль печати.
Вход на рассказ добавлен на первый экран главной и страницу «Страшных сказок».

Иллюстрация создана в SYNTX AI, Nano Banana 2, 2K, 16:9: одна генерация,
3 токена из существующего баланса. Сцена показывает коридор новостройки,
Мишу и закрытую дверь, сохраняя развязку. Исходник и сведения о сессии
хранятся в непубличном проектном архиве. На сайте используются WebP
1920×1080 / 76 402 байта и 960×540 / 19 028 байт; для социальных превью —
JPEG 1200×630. Метаданные исходного изображения не переносятся.

Страница проверена в браузере на 320, 390, 768 и 1440 px; текст 18–20 px,
без горизонтальной прокрутки. В `sitemap.xml` четыре публичных URL.

## Статистика читательских действий

Счётчики в этот выпуск не включены: Vercel endpoint
`/_vercel/insights/script.js` возвращает 404, а CLI сообщает, что текущий
токен недействителен. После входа в кабинет нужно проверить доступный план
аналитики, подключить рабочий сбор и отдельно проверить поступление событий
«читать бесплатно», «выбор площадки», «Telegram». До этого переходы не считаются.

## Внешний вид и книги

Возвращены исходные Oswald, янтарный свет, мерцание отдельных букв имени и
ночная улица сразу после первого экрана. Слова имени не разрываются на буквы.
Сетка книг подбирает колонки с минимальной шириной 250 px, на узких экранах
остаётся одна колонка. Заголовки и метки имеют согласованные высоты,
ссылки выровнены по нижнему краю карточек.

Сохранены шесть прежних книг. Добавлены новая бесплатная редакция «Страшных
сказок», самостоятельный роман «Реестр душ» (рукопись завершена, пока ссылка
на новости) и отдельный блок «Не хочу быть как все» с бесплатным чтением.
«Реестр душ» не является третьей книгой «Несущих».

## Медиа и управление

Девять обложек используют `data-live`. Все прежние файлы сохранены без изменений.
Три новых ролика Syntx: 5 секунд, 24 fps, H.264, без звука, faststart.
Оригиналы Syntx сохранены в проектном архиве отдельно от версии для сайта.

На компьютере обложки оживают при наведении или фокусе; явная кнопка доступна
на всех экранах. На телефоне видеообложки загружаются только по нажатию.
Ошибка видео оставляет статичную обложку и кнопку «Повторить видео».
Кнопка не вложена в ссылку на книгу. Явная остановка действует до следующего
нажатия; запуск другой обложки не блокирует её обычное наведение.

У трёх фоновых сцен есть настоящие WebP-постеры общим размером 34 636 байт.
Они видимы при выключенной анимации, отсутствии JavaScript и сбое видео.
Фоновые ролики подключаются при приближении к сцене; одновременно играет
только наиболее видимая сцена. Для видео в HTML задано `preload="none"`.

Общий переключатель показывает текущее состояние «Анимация: вкл/выкл»,
сохраняет выбор и учитывает системное уменьшение движения. В скрытой вкладке
останавливаются видео, таймеры и CSS-анимации. Фрагмент книги доступен без JS.

## Домен и проверка сети — 6 ноября 2026

DNS в РЕГ.РУ: `A @ → 76.76.21.21`, `CNAME www → greggrim.ru`,
NS `ns1.reg.ru` / `ns2.reg.ru`. Google DoH и Cloudflare DoH подтверждают эту зону.
`www` перенаправляется на основной адрес.

Обычный DNS-путь проверявшего компьютера продолжает отдавать `216.198.79.1`.
В этой сети с браузерным сжатием HTML основного домена загружается полностью:
55 916 байт до этого выпуска, 14 990 байт по сети, 0,190 с. Прежняя проверка
без сжатия не воспроизводила браузерный запрос; вывод о неполной загрузке
самого HTML уточнён.

При этом бинарные ресурсы по основному домену обрывались: обложка 64 126 байт
и ролик 298 675 байт не завершались за 15 с. Те же файлы через
`greg-grim-site.vercel.app` загрузились полностью за 0,799 и 0,663 с.
Поэтому ресурсы направлены через этот адрес без изменения canonical или DNS.
Это проверенный обход проблемы текущего сетевого маршрута, а не утверждение
о доступности каждого адреса во всех сетях. После публикации отдельно
проверяются полные ответы и CORS для шрифтов.

не запускается, пользователь поручил продолжить без него. Старые скриншоты
не считаются доказательством внешнего вида этого выпуска. Проверка на
320/390/768/1440 px остаётся отдельным следующим шагом после восстановления
инструмента. Уменьшение HTML за счёт вынесения CSS/JS не означает такого же
уменьшения общего трафика; выигрыши здесь — кэширование и отложенные видео.

## Локальный просмотр

`python -m http.server 8765 --bind 127.0.0.1` из папки сайта.
HTML ссылается на опубликованные ресурсы того же Vercel-проекта; до публикации
новой версии для полностью автономного просмотра нужно заменить в копии
префикс `https://greg-grim-site.vercel.app/assets/` на `assets/`.
