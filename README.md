# Грег Грим — сайт писателя

Официальный сайт писателя Грега Грима: хоррор, нуар, дарк-фэнтези.

**Основной адрес:** https://greggrim.ru

**Адрес Vercel:** https://greggrim.vercel.app

**Книги автора на Литрес:** https://www.litres.ru/author/greg-grim/

## Устройство

Один файл — `index.html`, без сборки и зависимостей (кроме Google Fonts).
Пуш в ветку `main` автоматически выкладывается на Vercel.

## Книжная полка и анимации

В библиотеке сохранены шесть прежних книг, добавлены карточка самостоятельного
романа «Реестр душ» (рукопись завершена, ссылка на новости) и отдельный блок
«Не хочу быть как все» со ссылками на бесплатное чтение. Новая редакция
«Страшных сказок» остаётся первым входом для читателя.

Девять обложек используют `data-live`. Три новых ролика созданы в Syntx AI и
оптимизированы для сайта: 5 секунд, 24 fps, H.264, без звука, faststart. Оригиналы
остаются отдельно от облегчённых файлов. Для новой обложки достаточно указать
существующий MP4 в `data-live` на контейнере `.cover` или `.start-cover`.

Кнопка «Без анимации» доступна при любой прокрутке и сохраняет выбор читателя.
Видео останавливаются в скрытой вкладке; при ошибке видео остаётся статичная
обложка. Фрагмент книги читается и без JavaScript.

## Домен

Домен `greggrim.ru` зарегистрирован в РЕГ.РУ и подключён к существующему
проекту Vercel `bird11/greg-grim-site`. DNS управляется в РЕГ.РУ:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 76.76.21.21 |
| CNAME | www | greggrim.ru |

В Vercel версия с `www` перенаправляет на `https://greggrim.ru` кодом 308.
NS-серверы остаются `ns1.reg.ru` и `ns2.reg.ru`.

6 ноября 2026 года рекомендованный Vercel адрес `216.198.79.1` возвращал HTTP
200, но полная страница обрывалась после 13 678 байт из 48 523. Через официальный
поддерживаемый Vercel адрес `76.76.21.21` та же страница загрузилась целиком;
после нормализации переносов строк она совпала с исходником. Поэтому здесь
используется этот адрес. Не заменяйте его только из-за рекомендации в панели:
сначала проверьте полную загрузку страницы из сети целевых читателей.

Обновление зоны у РЕГ.РУ занимает 15–60 минут; DNS-кэш у провайдеров может
сохранять прежние значения дольше.

## Локальный просмотр

Запустите `python -m http.server 8765 --bind 127.0.0.1` из папки сайта,
затем откройте `http://127.0.0.1:8765`.
